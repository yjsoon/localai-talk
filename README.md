# Local AI, explained with food

A 10-minute introduction to local AI by Yingjie Soon for Agentic Builders Collective.

[View the slides](https://yjsoon.github.io/localai-talk/)

## Build

Run `npm ci` then `npm run build`. The Marp source and speaker notes are in `deck.md`.

GitHub Pages serves the built deck from `docs/` on `main`. To update it, build the deck, copy `dist/` into `docs/`, and push.
